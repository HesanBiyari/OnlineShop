# OnlineShop

فروشگاه آنلاین ساخته‌شده با **Django**.

### Features

* 🛍️ مدیریت محصولات و Variantها
* 🛒 سبد خرید و سفارش
* 👤 احراز هویت کاربران
* 💳 پرداخت آنلاین
* 🎟️ کدهای دیجیتال
* ⚙️ پنل مدیریت
* 📱 طراحی Responsive

### Tech Stack

* Python / Django
* HTML / CSS / JavaScript
* SQLite / PostgreSQL

### Run

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
